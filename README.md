# GPAI 계산실

미적분, 재료역학, 열역학, 기하 계산 기능을 제공하는 공개 웹앱입니다.

- 웹앱: [GPAI 계산실](https://i71994453-create.github.io/-/)
- 실행·배포·AI 서버 설정: [docs/WEBAPP.md](docs/WEBAPP.md)
- C++ 계산 모듈과 공식 출처: [cpp/README.md](cpp/README.md)

## 기능과 처리 흐름

- **C++ 계산:** C++17 엔진이 브라우저 WebAssembly와 AI 백엔드 양쪽에서 수치 계산을 담당합니다. 허용 목록 기반 C ABI 디스패처가 35개 계산 함수만 실행합니다.
- **삽입 정렬:** 웹 화면에서 숫자 최대 1,000개를 오름차순·내림차순으로 정렬합니다. C++ WebAssembly 구현이며 입력값은 브라우저 안에서 처리합니다.
- **AI 풀이 안내:** Gemini는 자연어 문제를 읽고 계산 도구와 입력값을 선택합니다. Python API가 입력을 검증한 뒤 C++에 전달하고, 결과를 다시 AI에 보내 한국어 설명을 만듭니다.
- **Python 분야 분류:** 한국어 예시 48개로 학습한 작은 나이브 베이즈 모델이 문제 분야를 제안합니다. 정답이나 확률을 보장하지 않습니다.
- **웹 공개:** GitHub Pages는 정적 화면만 제공합니다. 자연어 AI에는 별도로 실행한 Python API와 서버 측 `GEMINI_API_KEY`가 필요합니다. 키는 HTML·JavaScript나 GitHub 저장소에 넣지 않습니다.

로컬 실행 절차는 [웹앱 문서](docs/WEBAPP.md)를 참고하세요. 재료역학과 열역학은 교육용 기초 공식이며 실제 설계·안전 검증을 대신하지 않습니다.

## 라이선스

저장소에 별도 라이선스가 없어 명시적 오픈소스 라이선스가 지정되지 않은 상태입니다. 공개 사이트에서 이용할 수 있다는 사실만으로 코드 재사용 권리가 부여되지는 않습니다.
