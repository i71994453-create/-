# GPAI 계산실

미적분, 재료역학, 열역학, 기하 기초 계산을 제공하는 공개 웹앱입니다.

- 웹앱: [GPAI 계산실](https://i71994453-create.github.io/-/)
- 웹앱·학습 모델·배포 문서: [docs/WEBAPP.md](docs/WEBAPP.md)
- C++ 계산 모듈, SI 단위와 수식 출처: [cpp/README.md](cpp/README.md)

## 구성

- **계산:** C++17 코어를 WebAssembly로 컴파일합니다. 브라우저에서 계산하므로 공개 사이트에 서버나 API 키가 필요하지 않습니다.
- **분야 안내:** Python 표준 라이브러리만 사용하는 학습 스크립트가 포함된 한국어 예시 48개로 나이브 베이즈 모델을 학습합니다. 모델은 빌드 과정에서 JSON으로 내보내집니다.
- **공개 배포:** GitHub Actions가 페이지 파일, 학습 결과, WebAssembly를 묶어 GitHub Pages에 배포합니다.

분류기는 분야를 제안할 뿐 문제를 풀지 않습니다. 작은 학습 예시로 만든 모델이므로 상대 점수를 확률이나 정답 보장으로 해석하면 안 됩니다. 재료역학과 열역학 계산은 교육용 기초 모델이며 실제 설계 검증을 대신하지 않습니다. 범위와 가정은 [웹앱 문서](docs/WEBAPP.md)에 기록했습니다.

## 폴더

- `cpp/`: 계산식, C ABI, WebAssembly export 목록 및 수식 문서
- `site/`: 정적 웹 화면
- `training/`: 분류 예시와 Python 학습 코드
- `.github/workflows/pages.yml`: 빌드와 Pages 배포

## 라이선스

저장소에 별도 라이선스가 없으므로 현재 코드는 명시적 오픈소스 라이선스가 지정되지 않은 상태입니다. 공개 사이트에서 이용할 수 있다는 사실만으로 코드를 재사용할 권리가 부여되는 것은 아닙니다.
