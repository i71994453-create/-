GGPAI 계산실

수학과 공학 계산을 한곳에서

문제를 분류하고,
검증 가능한 공식으로 계산합니다.

계산은 C++ WebAssembly로 브라우저에서 실행됩니다. Python으로 학습한 소형 분류기는 입력 문장의 분야를 찾아 계산 메뉴를 안내합니다.

01 / 문제 분야 안내

문제를 한 문장으로 입력하세요

분류 모델 불러오는 중
분류 결과가 이곳에 표시됩니다.

분류 모델은 포함된 예시 48개로 학습한 소형 나이브 베이즈 분류기입니다. 표시되는 점수는 보정된 확률이 아니며, 문제 풀이를 생성하지 않습니다.

02 / C++ 계산기

공식과 입력값을 선택하세요

C++ 엔진 불러오는 중

계산 결과가 이곳에 표시됩니다.

계산 범위와 주의점

  • 입력 기본 단위는 SI입니다. 온도는 K, 압력·응력은 Pa, 에너지는 J, 각도 출력은 rad 또는 표시된 단위를 사용합니다.
  • 재료역학 계산은 이상화된 선형 탄성 기초식입니다. 실제 구조물의 설계·안전 검증을 대신하지 않습니다.
  • 이상기체 계산은 이상기체 가정을 사용합니다. 실제 유체 상태나 상변화를 계산하지 않습니다.
  • 분류 모델과 계산은 API 키 없이 작동합니다. 이 사이트는 사용자의 입력을 GPAI 서버로 전송하지 않습니다.

공식, 단위, 대학 강의 자료와 학습·배포 방법은 웹앱 문서에서 확인할 수 있습니다.
